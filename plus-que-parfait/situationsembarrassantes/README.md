# Le plus-que-parfait — Les situations embarrassantes

Site pédagogique autonome en HTML.

## Publication avec GitHub Pages
1. Déposez `index.html` à la racine du dépôt.
2. Ouvrez Settings → Pages.
3. Dans Build and deployment, choisissez Deploy from a branch.
4. Sélectionnez `main` et `/ (root)`, puis enregistrez.

Le site fonctionne sans bibliothèque externe ni connexion réseau.
