# Les situations embarrassantes — Plus-que-parfait

Интерактивный урок французского языка для уровня A2–B1.

## Содержимое

- `index.html` — автономный интерактивный урок (HTML, CSS и JavaScript в одном файле).
- `.nojekyll` — служебный файл для корректной публикации через GitHub Pages.

## Локальный запуск

Скачайте `index.html` и откройте его в современном браузере. Интернет и установка зависимостей не нужны.

## Публикация через GitHub Pages

1. Загрузите содержимое этого пакета в корень репозитория `grammaire`.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку `main` и папку `/ (root)`, затем сохраните настройки.
5. После публикации сайт будет доступен по адресу:

   `https://<ВАШ_GITHUB_USERNAME>.github.io/grammaire/`

GitHub Pages может потребовать несколько минут для первой публикации.

## Технические заметки

Страница не использует внешние библиотеки, сборщик или сервер. Все стили, скрипты и данные словаря находятся внутри `index.html`.
