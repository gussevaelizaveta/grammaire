# Les situations embarrassantes — Plus-que-parfait

Интерактивный урок французского языка для уровня A2–B1.

## Содержимое

- `index.html` — автономный интерактивный урок (HTML, CSS и JavaScript в одном файле).
- `.nojekyll` — служебный файл для корректной публикации через GitHub Pages.

## Локальный запуск

Скачайте `index.html` и откройте его в браузере. Интернет и установка зависимостей не нужны.

## Технические заметки

Страница не использует внешние библиотеки, сборщик или сервер. Все стили, скрипты и данные словаря находятся внутри `index.html`.
