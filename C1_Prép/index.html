Grammaire · B2 → C1

Le participe passé

Formation, accords et cas particuliers — comprendre la logique avant de choisir la terminaison.
Durée indicative : 75–90 minRévision + approfondissementFiche élève

Objectifs du cours

À la fin de la séance, tu dois pouvoir :

  • former correctement les participes passés, y compris ceux des verbes irréguliers ;
  • justifier l’accord avec avoir, être et les verbes pronominaux ;
  • identifier la fonction de se, les, que et en dans une phrase ;
  • transformer un récit au passé simple en passé composé sans perdre les accords ;
  • repérer les cas où le participe passé reste invariable.
Le réflexe à adopter : ne commence jamais par chercher « masculin ou féminin ? ». Commence par identifier l’auxiliaire, puis le COD et sa place par rapport au participe passé.

1. Former le participe passé

Les formes régulières

InfinitifParticipe passéExemple
verbes en -er-éparler → parlé
beaucoup de verbes en -ir-ifinir → fini, grandir → grandi
certains verbes en -re / -oir-uvendre → vendu, voir → vu

Les participes passés en -i, -is et -it

Pour distinguer ces formes, on peut parfois mettre le participe au féminin : le -e ajouté permet de retrouver la terminaison.

MasculinFémininInfinitif

mismisemettre

Attention : cette astuce aide à reconnaître la terminaison, mais elle ne remplace pas l’apprentissage des formes irrégulières.

Quelques familles utiles à mémoriser

TerminaisonVerbes et participes passés
-ifinir → fini ; rire → ri ; suivre → suivi ; suffire → suffi ; cuire → cuit (attention : forme en -it)
-ismettre → mis ; prendre → pris ; apprendre → appris ; comprendre → compris ; acquérir → acquis ; conquérir → conquis ; asseoir → assis
-itécrire → écrit ; conduire → conduit ; traduire → traduit ; détruire → détruit ; séduire → séduit

Autres formes fréquentes : résoudre → résolu ; réduire → réduit ; produire → produit ; construire → construit ; attendre → attendu ; applaudir → applaudi ; haïr → haï.

Cas particuliers : absoudre, dissoudre et bénir

  • Absoudre : absous (masculin), absoute (féminin). La cycliste a été absoute.
  • Dissoudre : dissous (masculin), dissoute (féminin). L’association a été dissoute.
  • Bénir : béni comme participe passé. Comme adjectif, bénit / bénite s’emploie notamment pour des objets consacrés par un prêtre : de l’eau bénite.

2. L’accord avec avoir

Règle générale : avec l’auxiliaire avoir, le participe passé ne s’accorde pas avec le sujet.

Elle a écrit trois lettres. · Ils ont regardé le film.

Exception : le participe passé s’accorde avec le COD si celui-ci est placé avant le verbe.

COD après le verbeCOD avant le verbe
J’ai mangé les frites.
Pas d’accord : COD après.		Les frites que j’ai mangées.
Accord avec que (= les frites), féminin pluriel.
Elle a invité ses amies.Les amies qu’elle a invitées.
Question décisive : « qui ? » ou « quoi ? » après le verbe, sans préposition. Si la réponse est un COD placé avant le participe, on accorde.
Ne confonds pas COD et COI. Dans Elle leur a répondu, leur est COI (répondre à quelqu’un) : aucun accord. Dans Elle les a vus, les est COD : accord.

3. L’accord avec être

Règle : avec l’auxiliaire être, le participe passé s’accorde généralement avec le sujet.

SujetExemple
féminin singulierElle est arrivée.
masculin plurielIls sont partis.
féminin plurielElles sont revenues.

La règle vaut aussi à la forme passive :

Les candidates ont été invitées. · Les tableaux ont été vendus.

Attention à « on » : si on signifie « nous », l’accord peut se faire avec les personnes désignées : Mon frère et moi, on est allés au cinéma. Si on est indéfini (= quelqu’un / les gens), le masculin singulier est la forme habituelle : On est venu me voir.

4. Les verbes pronominaux : le point central

Les verbes pronominaux se construisent avec un pronom réfléchi : me, te, se, nous, vous. Avec eux, il faut déterminer la fonction de ce pronom.

A. « Se » est COD → accord

Le sujet fait l’action sur lui-même. On peut demander « qui ? quoi ? » sans préposition.

Elle s’est lavée. (Elle a lavé qui ? elle-même.)

Ils se sont rencontrés. (Ils ont rencontré qui ? l’un l’autre.)

B. « Se » est COI → pas d’accord avec « se »

Le verbe se construit avec à : parler à quelqu’un, écrire à quelqu’un, téléphoner à quelqu’un, se sourire, se nuire…

Elles se sont téléphoné. (Téléphoner à qui ? à elles.)

Ils se sont écrit des messages. (Écrire à qui ? à l’un l’autre.)

C. Un COD autre que « se » est placé avant → accord avec ce COD

Les lettres qu’elles se sont écrites. (Écrire quoi ? les lettres ; COD avant.)

La voiture qu’ils se sont achetée. (Acheter quoi ? la voiture ; COD avant.)

D. Le COD est placé après → pas d’accord

Elles se sont écrit des lettres. (COD après.)

Ils se sont acheté une voiture. (COD après.)

E. Verbes essentiellement pronominaux

Certains verbes s’emploient normalement sous forme pronominale : s’évanouir, s’enfuir, se souvenir, s’en aller, s’efforcer… Le participe passé s’accorde avec le sujet.

Elle s’est évanouie. · Ils se sont enfuis. · Elles se sont efforcées de comprendre.

Astuce d’analyse : reformule la phrase sans le pronom quand c’est possible : Elle a lavé qui ? → elle-même (COD) ; Elle a parlé à qui ? → à lui (COI). C’est la construction du verbe qui décide.

5. Passé simple → passé composé

Dans un récit, le passé simple exprime souvent des actions achevées et successives. À l’oral et dans de nombreux écrits contemporains, on utilise plutôt le passé composé.

Passé simplePassé composé
il pritil a pris
ils furentils ont été
elle détruisitelle a détruit
ils suivirentils ont suivi
il conduisitil a conduit
elles vinrentelles sont venues
Méthode : identifie l’infinitif et l’auxiliaire, conjugue l’auxiliaire au présent, puis ajoute le participe passé. Termine par la vérification de l’accord.

Exemple : Les fugitifs prirent du retard. → Les fugitifs ont pris du retard.

6. Méthode express : vérifier un participe passé

  1. Repérer l’auxiliaire. Avoir, être ou verbe pronominal ?
  2. Avec avoir : chercher le COD. Est-il placé avant le participe passé ? Si oui, accord avec lui ; sinon, pas d’accord.
  3. Avec être : identifier le sujet et accorder avec lui, y compris à la forme passive.
  4. Avec un verbe pronominal : analyser la fonction de se (COD ou COI), puis vérifier s’il existe un autre COD placé avant.
  5. Relire : genre, nombre et terminaison du participe passé.
Piège fréquent : le pronom nous ou vous n’est pas automatiquement COD. Compare Elle nous a vus (voir quelqu’un : COD) et Elle nous a répondu (répondre à quelqu’un : COI).

7. Entraînement

Fais les exercices sans consulter les rappels. Pour les questions d’accord, justifie au moins deux réponses à voix haute en nommant le COD, le COI ou le sujet.

Exercice 1 — Choisir la bonne forme

Complète avec le participe passé correct.

  1. L’actrice a __________ le public. séduire
  2. Le poulet a __________ au four pendant deux heures. cuire
  3. Cette sauce au vin a __________. réduire
  4. Le professeur a __________ un étudiant. applaudir
  5. Cet homme a __________ à l’étranger. conduire
  6. Les albums de Tintin ont été __________ en une cinquantaine de langues. traduire
  7. Trois heures n’ont pas __________ aux randonneurs pour atteindre le refuge. suffire
  8. François a __________ à Valérie. sourire
  9. Le magasin n’a pas __________ à nous faire une ristourne. consentir
  10. Sa mère a toujours __________ le mensonge. haïr
Corrigé et explications
  1. séduit
  2. cuit
  3. réduit
  4. applaudi
  5. conduit
  6. traduits
  7. suffi
  8. souri
  9. consenti
  10. haï

Ces formes se mémorisent par familles : séduire → séduit ; cuire → cuit ; réduire → réduit ; traduire → traduit ; suffire → suffi ; sourire → souri ; consentir → consenti ; haïr → haï.

Exercice 2 — Passé simple → passé composé

Transforme les phrases. Attention à la place des pronoms COD.

  1. À leur départ, les fugitifs prirent du retard.
  2. Leurs complices ne les accueillirent pas comme prévu au point de rendez-vous.
  3. On reconduisit les prisonniers à Paris.
  4. La foule envahit le Palais du roi.
  5. Elle détruisit les bustes de Louis XVI.
  6. Tout le monde connaît les événements qui suivirent.
Corrigé
  1. À leur départ, les fugitifs ont pris du retard.
  2. Leurs complices ne les ont pas accueillis comme prévu au point de rendez-vous. (les = COD placé avant, masculin pluriel.)
  3. On a reconduit les prisonniers à Paris.
  4. La foule a envahi le Palais du roi.
  5. Elle a détruit les bustes de Louis XVI.
  6. Tout le monde connaît les événements qui ont suivi. (qui est sujet de suivre.)

Exercice 3 — Accord : -s, -t, -e, -s

Complète si nécessaire. N’oublie pas les accords.

  1. Armelle s’est inscrit___ en fac de droit.
  2. Les albums ont été traduit___ en plusieurs langues.
  3. François a souri___ à Valérie.
  4. Le magasin a consenti___ à nous faire une ristourne.
  5. Les lettres qu’elles se sont écrit___ étaient touchantes.
  6. Les deux amis se sont téléphon___ pendant une heure.
  7. Les candidates ont été choisi___ par le jury.
  8. Ils se sont lav___ les mains avant de passer à table.
Corrigé et justifications
  1. inscrite — verbe pronominal, se = COD ; accord avec Armelle.
  2. traduits — forme passive ; accord avec albums.
  3. souri — sourire à quelqu’un ; pas de COD, forme invariable ici.
  4. consenti — consentir à ; pas de COD.
  5. écrites — se = COI, mais COD « les lettres » placé avant.
  6. téléphoné — téléphoner à quelqu’un ; se = COI.
  7. choisies — forme passive ; accord avec candidates.
  8. lavé — se = COI dans « laver quelque chose à soi-même » ; COD « les mains » après le verbe.

Exercice 4 — Les verbes pronominaux : expliquer l’accord

Choisis la forme correcte et explique pourquoi.

  1. Les joueurs se sont (félicité / félicités) après le match.
  2. Mes deux collègues se sont (écrit / écrits) des messages.
  3. Les messages qu’ils s’étaient (écrit / écrits) étaient émouvants.
  4. Les mariés se sont (embrassé / embrassés) devant leurs familles.
  5. Elle s’est (lavé / lavée) les cheveux.
  6. Les cheveux qu’elle s’est (lavé / lavés) sont encore mouillés.
  7. Ils se sont (rendu / rendus) compte de leur erreur.
  8. Elles se sont (souvenu / souvenues) de cette journée.
Corrigé détaillé
  1. félicités — féliciter quelqu’un : se est COD, accord avec le sujet.
  2. écrit — écrire à quelqu’un : se est COI ; le COD « des messages » est après.
  3. écrits — se est COI, mais « les messages » est COD placé avant.
  4. embrassés — embrasser quelqu’un : se est COD.
  5. lavé — laver quoi ? les cheveux ; COD après le verbe. Se est COI.
  6. lavés — COD « les cheveux » placé avant le participe.
  7. rendu — dans « se rendre compte », le groupe « compte » suit le verbe ; pas d’accord avec se.
  8. souvenues — se souvenir est essentiellement pronominal ; accord avec le sujet féminin pluriel.

Relie chaque phrase à la bonne explication. Plusieurs phrases peuvent relever de la même règle.

Exercice 6 — Texte à trous : la mort de Charles VIII

Accorde les participes passés si nécessaire. Lis d’abord tout le texte, puis justifie les accords les plus délicats.

Le matin du 7 avril 1498, le roi a commencé sa journée en allant à la chasse puis, après être rentré___, il a rendu visite à sa femme, Anne de Bretagne. Il l’a alors invité___ à une partie de jeu de paume, ce qu’elle a accepté___. Tous deux sont passé___ par la cour et les appartements du roi, ont descendu un escalier qui donnait sur une petite porte qu’ils ont emprunté___. Au moment de passer la porte, Charles VIII s’est brutalement cogné___ la tête au linteau. Mais il a été seulement un peu sonné___ et a poursuivi___ son chemin. La reine qui l’avait suivi___ ne s’est pas plus inquiété___ que lui. Ils se sont installé___ avec leurs amis et ont regardé___ la partie qui avait déjà commencé___. Tout à coup, le roi est tombé___. Tout le monde a accouru___, lui a posé___ des questions auxquelles il n’a pas répondu___. Les médecins, qui ont été appelé___ précipitamment, se sont efforcé___ de l’aider, en vain. Le roi avait rendu___ l’âme à cause d’une porte trop basse.

Corrigé complet

rentré · invitée · accepté · passés · empruntée · cogné · sonné · poursuivi · suivi · inquiétée · installés · regardé · commencé · tombé · accouru · posé · répondu · appelés · efforcés · rendu

À retenir : l’ dans « l’avait suivi » renvoie au roi (masculin singulier), tandis que « l’ » dans « l’a invitée » renvoie à Anne (féminin singulier). Dans « s’est cogné la tête », le COD « la tête » est après le verbe et se est COI. « S’efforcer » est essentiellement pronominal : accord avec « les médecins ».

Exercice 7 — Production et correction (B2–C1)

Réécris ce court récit au passé composé. Fais attention aux accords et conserve le sens.

La chercheuse découvrit plusieurs lettres dans les archives. Elle les lut attentivement, puis elle se rendit compte qu’elles avaient été écrites par une femme dont les historiens avaient longtemps ignoré l’existence. Ses collègues se parlèrent de cette découverte et se promirent de vérifier les dates. Les informations qu’ils recueillirent furent ensuite publiées dans une revue spécialisée.

Consigne complémentaire : choisis cinq participes passés de ton texte et justifie leur forme en une phrase grammaticale précise.

Proposition de corrigé

La chercheuse a découvert plusieurs lettres dans les archives. Elle les a lues attentivement, puis elle s’est rendu compte qu’elles avaient été écrites par une femme dont les historiens avaient longtemps ignoré l’existence. Ses collègues se sont parlé de cette découverte et se sont promis de vérifier les dates. Les informations qu’ils ont recueillies ont ensuite été publiées dans une revue spécialisée.

Points à expliquer : lues : COD « les » avant ; rendu : locution « se rendre compte », pas d’accord ; écrites : forme passive, accord avec « elles » ; parlé : parler à quelqu’un, se COI ; promis : promettre quelque chose à quelqu’un, se COI et COD « de vérifier… » après ; recueillies : COD « les informations » avant ; publiées : forme passive, accord avec « informations ».

Les questions à se poser avant de valider une phrase

  1. Quel est l’infinitif du verbe ? Est-ce que je connais son participe passé ?
  2. Quel auxiliaire est utilisé ?
  3. Quel est le COD ? Est-il avant ou après le participe ?
  4. Si le verbe est pronominal, se est-il COD ou COI ?
  5. Quel élément commande réellement l’accord : le sujet ou le COD antéposé ?

9. Bilan de fin de séance

Réponds oralement, sans regarder la fiche :

  1. Pourquoi écrit-on les chansons qu’elle a entendues, mais elle a entendu des chansons ?
  2. Quelle différence grammaticale y a-t-il entre elles se sont vues et elles se sont parlé ?
  3. Pourquoi écrit-on les lettres qu’ils se sont écrites ?
  4. Pourquoi écrit-on elles se sont lavé les mains ?
  5. Comment expliquer l’accord dans les candidates ont été retenues ?
Réponses attendues
  1. Dans la première phrase, le COD « que » (= les chansons) est placé avant le participe ; dans la seconde, le COD est après.
  2. Dans « se voir », se est COD ; dans « se parler », se est COI (parler à quelqu’un).
  3. Se est COI, mais « les lettres » est COD placé avant le participe.
  4. « Les mains » est COD après le participe ; se est COI.
  5. La phrase est à la forme passive ; le participe passé s’accorde avec le sujet « les candidates ».
